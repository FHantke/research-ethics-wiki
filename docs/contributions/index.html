                                        How to Contribute#

                                        This research ethics wiki is the outcome of and based on a recent research paper1 a community-maintained resource. We welcome contributions from researchers, program committee members, ethics committee members, and anyone interested in advancing research ethics in security and privacy.

                                        To contribute, please open a pull request or start discussing a topic as an issue on GitHub.

                                        For both issues and pull requests, please indicate their purpose by applying the appropriate label:

                                        • Correction: Use this label when fixing incorrect or misleading information.
                                        • Discussion: Use this label for ethics-related topics that you want to discuss with the community.
                                        • Suggestion: Use this label for general proposals to improve the wiki.
                                        • Update: Use this label when updating existing information, such as conference policies.

                                        1. Authors. Reflection, Education, Consistency: Towards Best Ethics Practices At Security And Privacy Conferences. CCS 2026. ↩︎
